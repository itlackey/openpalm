# Installation

This page has been folded into the [Setup Guide](setup-guide.md), which is
the current reference for installing OpenPalm: interactive setup
(`setup.sh`/`setup.ps1`), headless setup (`openpalm install --file`), the
full generated runtime layout, and the Compose ownership model.

Do not use a raw copy of `packages/skeleton/` as an installation — see the
[Setup Guide](setup-guide.md) for why, and its
[Runtime Layout](setup-guide.md#runtime-layout) section for what a complete
install actually generates.

For manual Docker Compose operations after a generated install, see the
[Manual Compose Runbook](operations/manual-compose-runbook.md).
