Discord

Let approved Discord members talk to your agent.

Before enabling Discord
  1. Create an application and add a bot in the Discord Developer Portal.
  2. Enable the bot’s Message Content Intent.
  3. Invite it with permission to view channels, read message history, and send messages.
  4. Copy its bot token into OpenPalm’s private token storage.
  5. Add at least one allowed server, role, or user ID.
Who can use it

Leave a list empty to ignore it. If you fill more than one allowed list, every filled list must match. Blocked users are always denied. Separate IDs with commas.

Slack

Let approved Slack members talk to your agent.

Before enabling Slack
  1. Create a Slack app and enable Socket Mode.
  2. Create an app-level token with connections:write.
  3. Grant the bot app_mentions:read, chat:write, and the history scopes your channels need.
  4. Subscribe to app_mention and the message events those channels need, then install the app.
  5. Copy the bot and app-level tokens into OpenPalm’s private token storage.
  6. Add at least one allowed channel or user ID.
Who can use it

Leave a list empty to ignore it. If you fill both allowed lists, both the user and channel must match. Blocked users are always denied. Separate IDs with commas.
